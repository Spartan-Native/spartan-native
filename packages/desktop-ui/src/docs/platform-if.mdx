# Platform if

`*snPlatformIf` is a structural directive that renders its template only on the given operating systems, and
an optional `else` template everywhere else. It follows the active skin live. Use it for content that only makes
sense on some platforms: an Exit button on Windows and Linux, a note about the macOS menu bar, a link into KDE
System Settings. For styling differences use the `data-family` / `data-skin` attributes in CSS instead.

It accepts a skin, a family, or a list mixing both:

| OS | Skin | Family |
| --- | --- | --- |
| Windows 11 | `'win'` | `'windows'` |
| Windows 10 | `'w10'` | `'windows'` |
| macOS 26 | `'mac'` | `'macos'` |
| macOS 13–15 | `'macc'` | `'macos'` |
| GNOME | `'gtk'` | `'linux'` |
| KDE | `'qt'` | `'linux'` |
| ChromeOS | `'cros'` | `'chromeos'` |
| Unknown OS | `'web'` | `'web'` |

## API

### Inputs

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `snPlatformIf` | `PlatformMatch \| readonly PlatformMatch[]` | required | Where to render: a skin, a family, or a list. |
| `snPlatformIfElse` | `TemplateRef<unknown> \| null` | `null` | Rendered on every other platform (the `; else tpl` part). |

`PlatformMatch` is `Skin | PlatformFamily`. The template is created once and kept while the platform keeps
matching; it is destroyed and the other template created when the skin changes.

No outputs, slots or CSS hooks: it renders your template and nothing else.

## Accessibility

The directive adds no markup. Content that is not rendered is not in the DOM, so it is hidden from assistive tech
too; make sure every platform still gets a way to do the task (use `else`).
