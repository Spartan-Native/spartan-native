# @spartan-native/desktop-ui

The pieces stock spartan doesn't have: **window chrome** and the **patterns each OS is known for**. Each component changes its *layout* per OS, not just its colors. On its home OS it is the native control; everywhere else it becomes that platform's closest counterpart. Switch the OS in the toolbar to see it.

Every page below has the per-OS table, live examples, usage, the API and accessibility notes.
