# @spartan-native/helm

**Desktop behaviors** for stock spartan/ui. The look comes from `@spartan-native/theme`; helm adds how desktop apps *behave*.

| Directive | What it does |
| --- | --- |
| `snSelectable` + `snSelectableItem` | The desktop selection model for lists (`role="listbox"`) and tables (`snSelectable="grid"`): click, Shift/Ctrl/⌘-click, arrows, Home/End, PageUp/PageDown, Ctrl/⌘+A, Esc, type-ahead, Enter/double-click to open |
| `snDefaultAction` | Enter in the surrounding dialog or form presses this button |
| `snCancelAction` | Esc in the surrounding dialog or form presses this button |

Use the toolbar to switch the OS (⌘ replaces Ctrl on macOS), light/dark, transparency and window focus, and the Controls panel for the accent.
